================================================================================
                    MUMBAI TIFFIN SERVICE - HOW TO RUN
================================================================================

PROJECT STRUCTURE:
- client/     - React frontend
- server/     - Node.js/Express backend with MongoDB

--------------------------------------------------------------------------------
PREREQUISITES:
--------------------------------------------------------------------------------
1. Node.js installed (https://nodejs.org)
2. MongoDB installed and running locally (https://www.mongodb.com)

--------------------------------------------------------------------------------
STEP 1: INSTALL DEPENDENCIES
--------------------------------------------------------------------------------
Open terminal in project root (D:\Projects\tiffin-service) and run:

  npm install --prefix server
  npm install --prefix client

--------------------------------------------------------------------------------
STEP 2: CREATE FIRST ADMIN USER (one-time, per machine)
--------------------------------------------------------------------------------
  No "seed" script exists. Two supported ways to bootstrap your first admin:

  Option A (recommended) - Use the Admin Dashboard after registering a user:
    1. Register a regular account via the UI or POST /api/v1/auth/register.
    2. Open MongoDB Compass / mongosh and update that user's role to "admin".
    3. Login at http://localhost:3000/login and use the dashboard to add more.

  Option B - Direct database insert via mongosh:
    use tiffin-service
    db.users.insertOne({
      name: "Admin", role: "admin", email: "admin@tiffin.com",
      password: "<bcrypt-hash-of-admin123>", phone: "+91 12345 67890",
      address: { street: "1 Admin Street", area: "Andheri",
                city: "Mumbai", pincode: "400001" }
    })

  Demo accounts already in the MongoDB volume (created during Docker bring-up):
    admin@tiffin.com  / admin123
    user@tiffin.com   / user123

--------------------------------------------------------------------------------
STEP 3: START THE SERVER (Backend)
--------------------------------------------------------------------------------
  npm start --prefix server

Server will run on: http://localhost:5000

--------------------------------------------------------------------------------
STEP 4: START THE CLIENT (Frontend) - In a new terminal
--------------------------------------------------------------------------------
  npm start --prefix client

Client will run on: http://localhost:3000

--------------------------------------------------------------------------------
LOGIN CREDENTIALS:
--------------------------------------------------------------------------------
Admin Account:
  Email:    admin@tiffin.com
  Password: admin123

Demo User Account:
  Email:    user@tiffin.com
  Password: user123

--------------------------------------------------------------------------------
QUICK START (All commands in sequence):
--------------------------------------------------------------------------------
1. Open first terminal:
   npm install --prefix server
   npm install --prefix client
   npm start --prefix server

2. Open second terminal:
   npm start --prefix client

3. Open browser: http://localhost:3000

--------------------------------------------------------------------------------
HOW TO CREATE ADDITIONAL USERS (admin dashboard):
--------------------------------------------------------------------------------
1. First admin must already exist in MongoDB (see STEP 2 above).
2. Login as admin at http://localhost:3000/login
3. Go to the "Users" tab in the Admin Dashboard
4. Click "+ Add New User" button
5. Fill in details and select Role (User or Admin)
6. Create as many users/admins as needed

Regular users can also self-register:
  - Go to http://localhost:3000/register
  - Fill in details and create account
  - They will have "user" role by default

--------------------------------------------------------------------------------
TROUBLESHOOTING:
--------------------------------------------------------------------------------
- If MongoDB connection fails, ensure MongoDB service is running
- If port 5000 is in use, change PORT in server/.env file
- If port 3000 is in use, React will prompt to use another port
- If login fails, confirm the admin user exists in MongoDB (see STEP 2)
- If server crashes, restart it: npm start --prefix server

--------------------------------------------------------------------------------
ENVIRONMENT VARIABLES (server/.env):
--------------------------------------------------------------------------------
PORT=5000
MONGODB_URI=mongodb://localhost:27017/tiffin-service
JWT_SECRET=your-super-secret-jwt-key-change-in-production
